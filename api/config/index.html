Run configuration¶

Config ¶

The full validated config.yaml.

Config.load(path) is the entry point — it parses YAML, validates, cross-checks every reference, and returns this object. The accessors below hand the sweep what it needs with the references resolved.

language_models property ¶

language_models: list[str]

The sweep axis, by name.

default_language_model property ¶

default_language_model: Any

The evaluation's default language model: its id, or the model built with its entry's params.

default_embedding_model property ¶

default_embedding_model: Any

The evaluation's default embedding model: its id, or the model built with its entry's params.

metrics property ¶

metrics: list[MetricEntry]

The evaluation's metrics, added to every dataset's, their models resolved.

load classmethod ¶

load(path: str | Path) -> 'Config'

Parse + validate a YAML config file, each ${NAME} in it replaced by the environment variable (files.expand).

selected_dataset_names ¶

selected_dataset_names() -> list[str]

Datasets the sweep should run, in the evaluation's order.

model_id ¶

model_id(name: str) -> str

The litellm id an entry of the sweep axis calls: its models.<name>.model; an a2a sweep's axis is agent names, kept as they are.

lm_kwargs ¶

lm_kwargs(name: str) -> dict[str, Any]

Keyword arguments for LanguageModel(model=self.model_id(name), ...), or EmbeddingModel(...) for an embedding model.

Empty for a model with no params, in which case the program builders hand the framework the bare id.

dataset_entry ¶

dataset_entry(ds_name: str) -> dict[str, Any]

The flat mapping the dataset providers read (datasets.load_dataset_from_config).

resolved_agent ¶

resolved_agent(ds_name: str) -> dict[str, Any] | None

Per-dataset agent: block with mcp_servers: resolved against the top-level registry into {name: connection_dict} form (the shape MultiServerMCPClient(connections=...) expects). Returns None when the dataset uses a generator instead.

harbor_spec ¶

harbor_spec(ds_name: str) -> dict[str, Any]

A Harbor dataset's run: its block, and, over rows, its environment's entry and the MCP connections that environment names.

Over task folders (harbor_tasks), tasks is set and there is no environment: each task brings its own, and its own tests.

a2a_connection ¶

a2a_connection(name: str) -> dict[str, Any]

Where the A2A agent name on an a2a sweep's axis is: {url, headers, card_path, timeout_sec}.

reward_spec ¶

reward_spec(ds_name: str) -> dict[str, Any]

Reward spec ready for rewards.get(...): the dataset's reward entry, direction: stripped, models resolved.

An MCP agent answers with the schema's fields and its messages, the tool-calling transcript, which a target never carries; so a reward that sets no mask of its own gets out_mask: ["messages"], lest a reward comparing whole objects (exact_match) score every row 0. A Harbor trial answers with its whole ATIF trajectory, so such a reward reads its answer alone (in_mask: ["answer"]); the verifier's reward (SELF_SCORED) reads the trajectory's rewards. One that names masks is left as written, so a judge can be pointed at the steps on purpose.

dataset_metrics ¶

dataset_metrics(ds_name: str) -> list[MetricEntry]

Per-dataset metric entries (NOT merged with the evaluation's), their models resolved.

evaluation_config ¶

evaluation_config(configs: Path, name: str) -> dict

The config run_sweep reads for the evaluation saved as name in configs; see gather.
